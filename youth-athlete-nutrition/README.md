# 청소년 운동선수 식생활 관리 서비스 — Landing Page Sample

PPT 사업계획서를 바탕으로 만든 초기 랜딩페이지 샘플입니다.

## 핵심 메시지
- 무엇을 먹을지 알려주는 데서, 실제로 먹을 수 있게 만드는 데로
- 기록 → 분석 → 추천 → 실제 섭취 → 다시 기록
- 디지털 추천과 실제 식품을 하나의 루프로 연결

## 구성
- Hero
- Problem
- How it works
- Data loop
- CTA

단일 HTML 파일로 동작하며 외부 폰트(Google Fonts)를 제외한 별도 빌드 과정이 없습니다.

> 이 저장소의 내용은 서비스 컨셉 검증용 샘플이며 실제 의료·영양 처방을 의미하지 않습니다.
